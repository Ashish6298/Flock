# Security Policy

## Reporting a Vulnerability

We take the security of Flock seriously. If you find a vulnerability or potential security exploit, please do NOT report it publicly. 

Instead, report it privately to our security team. We will respond within 48 hours to coordinate validation, patching, and disclosure.

## Supported Versions

Only the current General Availability (GA) major version releases are supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |
