# Contributing to Flock

We are thrilled that you are interested in contributing to Flock! As a cutting-edge federated distributed computing platform, Flock thrives on community innovation.

## How to Contribute

1. **Reporting Bugs**: File an issue detailing steps to reproduce, expected behavior, and host environments.
2. **Feature Requests**: Submit a suggestion describing the feature's value and implementation path.
3. **Pull Requests**:
   - Fork the repository and create your branch from `main`.
   - Ensure `mypy --strict` passes with zero errors on your changes.
   - Run the full test suite with `python -m pytest tests/` to verify no regressions.
   - Maintain SOLID principles, strict type annotations, and comprehensive docstrings.
