7. DETAILED ROOT CAUSE ANALYSIS & FIXES APPLIED
------------------------------------------------
- Issue 1: Unused type-ignore comments in `src/flock/security/hardening.py`.
  - Root cause: Leftover type checks mapping.
  - Fix applied: Removed the unused `# type: ignore` comment on os.getuid().
- Issue 2: Sorting callback type mismatch in `src/flock/observability/profiling.py`.
  - Root cause: Lambda returned object type, violating strict comparison requirements.
  - Fix applied: Wrote explicitly annotated sorting helper function `_get_mean_ms`.
- Issue 3: no-any-return violation in `src/flock/dashboard/renderer.py`.
  - Root cause: The widget dispatcher was typed as Dict[str, Any], causing return type to resolve as Any.
  - Fix applied: Specified precise Callable annotations for all render callbacks.
