# Flock Project Roadmap

This document outlines the vision and development roadmap for Flock.

## v1.1.0 – Extensibility & Performance
- **Rego / Open Policy Agent (OPA) Integration**: Direct support for Rego policy translation.
- **Topological Dependency Graph Resolution**: Optimize task execution paths for multi-node tasks.
- **OCI Container Artifacts Registry**: Pull marketplace modules as standard container images.

## v1.2.0 – Operational Maturity
- **Automated Failover Rebalancing**: Auto-migrate workflow tasks on node quarantines.
- **Interactive UI Dashboards**: Release web console UI for fleet governance.

## v2.0.0 – Next-Gen Federation
- **Mesh Multi-Cloud Networks Routing**: Optimize cross-region latency limits.
- **Decentralized Resource Bidding**: Auction compute dynamically across organizations.
